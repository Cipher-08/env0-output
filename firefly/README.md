# CloudFormation EC2 Instance

This CloudFormation code creates an EC2 instance using an Amazon Machine Image (AMI) and instance type specified in the code, in the ap-south-1 region.

## Prerequisites

- AWS account with appropriate permissions
- AWS CLI installed on your machine

## Usage

1. Clone this repository
2. Navigate to the cloned directory
3. Run `aws cloudformation create-stack --stack-name <stack-name> --template-body file://ec2-instance.yaml` to create the CloudFormation stack and the EC2 instance
4. Run `aws cloudformation describe-stacks --stack-name <stack-name>` to get information about the stack and the EC2 instance
5. Run `aws cloudformation delete-stack --stack-name <stack-name>` to delete the CloudFormation stack and the EC2 instance

## Parameters

The following parameters can be set to customize the EC2 instance:

- `ImageId`: The ID of the Amazon Machine Image (AMI) to use for the EC2 instance.
- `InstanceType`: The instance type of the EC2 instance.
- `Region`: The AWS region where the EC2 instance will be created.

## Outputs

The following outputs are available:

- `PublicIp`: The public IP address of the EC2 instance.
- `PrivateIp`: The private IP address of the EC2 instance.
- `InstanceId`: The ID of the EC2 instance.

## Clean Up

To delete the CloudFormation stack and the EC2 instance, run `aws cloudformation delete-stack --stack-name <stack-name>`.
